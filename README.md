A pre-token radar: it reads the sealed DefiLlama snapshot, ranks every protocol that records no token by an implied value built from TVL, seven-day growth and time without a token, and pairs each row with a concrete farm plan.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
